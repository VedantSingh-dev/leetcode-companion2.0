# ⚡ LeetCode AI Companion 2.0

An AI-powered performance evaluation tool built with **Streamlit**, **LangChain**, and **Gemini 2.0**. It fetches real-time public stats from LeetCode and generates a personalized, highly structured 4-week Data Structures & Algorithms (DSA) preparation roadmap.

---
## Acess App here -> 
`https://leetcode-companion20-5qirpyacuydyboilp66qpo.streamlit.app/`
## ✨ Features

- **📊 Live Profile Fetching**: Retrives real-time stats directly from LeetCode (Total Solved, Easy/Medium/Hard breakdown, and Contest Rating).
- **🎯 Visual Performance Charts**: Interactive Plotly charts for topicwise distribution and difficulty ratios.
- **💡 Gemini-Powered AI Coach**: Generates tailored feedback highlighting blind spots, weak topics, and priority areas.
- **🗓️ 4-Week Actionable Roadmap**: Produces a week-by-week execution plan tailored to your current standing.
- **📥 One-Click Export**: Download your personalized study plan directly as a Markdown (`.md`) file.

---

## 🛠️ Tech Stack

- **Frontend**: [Streamlit](https://streamlit.io/)
- **Data Visualization**: [Plotly](https://plotly.com/python/)
